# Nocturne

An immersive, procedural meteor shower designed to feel like lying beneath a dark summer sky.

The scene picker uses real night-sky photographs:

- **Open sky:** NPS / Jeff Zylland, [The Milky Way Shines Bright](https://npgallery.nps.gov/AssetDetail/cbaf1f2f-1dd8-b71b-0b09-d6d4ae15bdc1).
- **Low horizon:** Bettymaya Foott / NPS, [Fajada Butte and the Milky Way](https://npgallery.nps.gov/AssetDetail/df5250b9-69ac-4334-8b9b-364016606f68).
- **Desert tree:** NASA / Preston Dyches, [Milky Way over the California desert](https://science.nasa.gov/image-detail/milkyway-desrt-tree-credit-preston-dyches-2/).

## Run locally

```bash
npm run dev
```

Then open <http://localhost:4173>. The scene has no runtime dependencies.
